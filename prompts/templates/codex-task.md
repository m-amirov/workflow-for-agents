# Шаблон самодостаточной задачи Codex

## Цель
Опиши наблюдаемое желаемое поведение и зачем оно необходимо.

## Контекст
Репозиторий, текущая ветка/PR при наличии, факты об ошибке, входные данные, уже выполненные проверки и подтверждённые решения.

## Обязательное исследование
Самостоятельно исследуй кодовую базу, найди правильное место изменения, реальные контракты, зависимости и связанные тесты. Не предполагай пути файлов заранее.

## Ограничения
- Минимальные изменения без необоснованного рефакторинга.
- Сохрани существующее поведение, стиль, интерфейс и утверждённые решения.
- Если это баг, исправь root cause и по возможности добавь regression coverage.
- Не скрывай ошибки, не подменяй тесты, не выводи PASS из чужого отчёта.
- Учитывай безопасность и сохранность данных.

## Реализация
Перечисли обязательные пользовательские сценарии, ошибочные и крайние случаи.

## Acceptance criteria
Укажи измеримые результаты: функции, UI, обработка ошибок, обратная совместимость, тесты.

## Проверки
Выполни реально применимые lint/typecheck/unit/integration/e2e/visual проверки, сверяй результаты с exact HEAD. Если запуск невозможен, явно укажи NOT RUN/BLOCKED и причину.

## Релиз (если относится к задаче)
Сформулируй release gates отдельно. **Не объявляй релиз готовым, пока каждый обязательный gate фактически не пройден.**

## Итог
Что изменено; реальные команды/результаты; оставшиеся риски; что не проверено; следующий шаг.
