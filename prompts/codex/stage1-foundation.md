# Задача для Codex: завершить Foundation

## Цель

Довести `m-amirov/workflow-for-agents` до рабочего базового стандарта, устанавливаемого и проверяемого в Codex на Windows, без преждевременного создания сложной агентной платформы.

## Контекст

Изучи `README.md`, `AGENTS.md`, `docs/PLAN.md`, `docs/ARCHITECTURE.md`, `docs/ROADMAP.md`, каталог Skills и реальные файлы репозитория. Не принимай галочки roadmap за подтверждение фактического качества.

## Реализация

1. Проведи аудит начальных Skills на соответствие Agent Skills specification и дополни комплект до 8–10 базовых навыков без дублирования правил.
2. Реализуй `scripts/install.ps1`: выбор конкретных Skills, user/project scope, Windows, dry-run, список изменений, отказ от перезаписи конфликтующих данных, manifest версии.
3. Реализуй `scripts/sync.ps1`: обнаружение локальной модификации, безопасное обновление, явное разрешение конфликтов, no silent overwrite.
4. Добавь переносимые статические проверки YAML metadata, описаний, ссылок, файлов скриптов и дублирующихся имён.
5. Добавь минимальные позитивные/негативные eval-кейсы и проверку репозитория в CI (без чрезмерной матрицы).
6. Обнови README/инструкции установщика на основании реально работающих возможностей.

## Ограничения

Исследуй актуальные документы Codex. Не предполагай имена исходных файлов и места изменений. Не ставь внешние зависимости без необходимости. Не меняй исходные репозитории Ludory, Eskizno и других проектов. Не создавай сложную оркестрацию и поиск.

## Приёмка

- Установка user/project работает на реальном Windows PowerShell (либо явно BLOCKED, если среда недоступна).
- Повторный install идемпотентен.
- Любой изменённый установленный файл защищён от перезаписи.
- Sync показывает версии, diff/conflict, не теряет локальные изменения.
- Валидатор обнаруживает сломанный frontmatter, дубли имён, отсутствующий ресурс.
- При положительном и отрицательном запросе проверена активация двух навыков; где реальный Codex недоступен, не выдавать симуляцию за интеграционный PASS.
- CI тестирует нужные свойства; результат привязан к точному commit.

## Выпуск

Подготовить PR с диффом и тестовыми доказательствами. Не объявлять Foundation готовым без выполнения всех обязательных gates в `docs/ROADMAP.md`.
