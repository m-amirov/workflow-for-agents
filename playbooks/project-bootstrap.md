# Playbook: подключение нового проекта

1. Изучить репозиторий проекта, цели, соглашения, окружения и существующий AGENTS.md.
2. Выбрать минимальный профиль Skills из центрального каталога.
3. Создать проектный индекс в `projects/`: репозиторий, устойчивые решения, ссылки, владельцы, версия профиля.
4. Согласовать проектные дополнения к правилам и приоритет источников истины, включая main-first и исключения для защищённой `main` (PR, CI, review).
5. Установить только выбранные навыки в рекомендованное проектное расположение.
6. Проверить, что агент действительно обнаруживает Skill и активирует его на релевантном кейсе.
7. Зафиксировать версию источника, способ синхронизации и результат проверки.

Установщик и lockfile запланированы, но должны быть реализованы и проверены отдельно.
