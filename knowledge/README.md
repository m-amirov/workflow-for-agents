# Knowledge: проверенный опыт

Материалы собираются по доказательствам, а не по обрывкам воспоминаний агента.

- `incidents/` — разбор конкретного сбоя: факт, среда, причина, исправление, проверка.
- `decisions/` — принятые решения (ADR), альтернативы, последствия, дата/статус.
- `patterns/` — повторяющиеся работающие подходы с условиями применимости.
- `research/` — исследования, источники, актуальность и уровень уверенности.
- `lessons/` — выводы и анти-паттерны, которые ещё не требуют отдельного Skill.

## Правило

Не переносить «всё полезное» из PR без проверки. Каждая запись должна отличать наблюдение, подтверждённый вывод, гипотезу и рекомендацию; содержать ссылки на доступный источник и границы применимости.

Шаблон инцидента находится в [KNOWLEDGE_LIFECYCLE.md](../docs/KNOWLEDGE_LIFECYCLE.md). Пока каталог пуст, не утверждать, что знания о конкретных ошибках перенесены.
