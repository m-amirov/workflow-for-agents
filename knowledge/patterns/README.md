# Patterns

Подтверждённые переиспользуемые подходы, условия применения, контрпримеры и ссылки на исходные доказательства. Процедуру с явным триггером лучше оформить как Skill.

Каждый pattern (кроме этого README) имеет YAML metadata: `title`, `status` (`VERIFIED`, `PARTIAL` или `UNKNOWN`), `source_repository`, exact `source_sha` и `reuse_scope`. Обязательные разделы: контекст, механизм, алгоритм, ограничения/антипримеры, источники и проверка повторного применения. Это проверяет `python scripts/validate.py`.
