# Scripts: целевое поведение (запланировано)

## install.ps1

**Inputs:** набор Skills, `scope=user|project`, destination, dry-run.

**Expected:** переносит выбранные каталоги Skills в плоскую структуру, совместимую с Codex, сохраняет version/source manifest, отображает список изменений, не перезаписывает существующие изменённые файлы без явного разрешения, поддерживает Windows PowerShell.

## sync.ps1

**Inputs:** установленный manifest, исходная версия/commit, режим dry-run.

**Expected:** сравнивает источники и установленные файлы, распознаёт изменения пользователя, сообщает конфликт и не затирает его, обновляет незатронутые файлы, оставляет отчёт о результате.

## validate.py (или эквивалент)

**Expected:** проверка структуры Skills, YAML frontmatter, одинаковых имён, сломанных ссылок, путей ресурсов, каталога, формата evals. Без необязательных тяжёлых зависимостей.

## Release gates

Установщик и синхронизатор должны проверяться на временной директории, повторных установках, конфликтующих локальных правках, некорректных inputs, Windows путях, dry-run и recoverable errors.

**Статус:** эти исполняемые файлы пока отсутствуют; текущий README — требование, а не реализация.
