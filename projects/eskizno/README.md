# Project profile: Eskizno

**Репозиторий:** https://github.com/m-amirov/eskizno

**Назначение индекса:** проверенные знания об адаптивном рисовальном редакторе, сенсорном вводе, загрузке изображений, холсте, слоях и UX.

**Кандидаты Skills:** visual-audit, responsive-design, interaction-design, browser-qa, drawing-editor.

**План миграции:** проверить конкретные версии исправлений и сценарии на планшете и десктопе; сохранить только доказанные наблюдения и воспроизводимые тесты.

**Статус:** проект зарегистрирован; конкретные технические решения ещё не импортированы.
