# Project profile: Ludory

**Репозиторий:** https://github.com/m-amirov/ludory

**Назначение индекса:** навигация по устойчивым подходам разработки игрового фреймворка, CLI/Studio/Runtime, проверкам и релизным сценариям. Это **не** копия актуальной архитектуры Ludory.

**Подключаемые central Skills:** `codebase-exploration`, `regression-testing`, `release-verification`, `git-workflow`, `browser-qa`. `game-visual-integrity` имеет статус planned и не подключается.

**План миграции:** после изучения актуального кода/PR отобрать подтверждённые регрессионные случаи, release gates и способы проверки игровых ассетов. Не переносить неподтверждённые исторические статусы.

**Профиль:** [profile.json](profile.json), проверен на `933c73b195eaf3bfffd12a31ab1cbadb27989eea`. Локальные `ludory-*` Skills, frozen games, права ассетов и platform acceptance не заменяются central Skills. См. [inventory](../../knowledge/research/project-inventory.md).
