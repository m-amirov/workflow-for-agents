# Project profile: Twork automation

**Репозиторий:** https://github.com/m-amirov/task-playwright-desktop

**Назначение индекса:** методы работы с устойчивой UI-автоматизацией, журналами выполнения, классификацией и документами.

**Кандидаты Skills:** browser-automation, classification-quality, document-extraction, root-cause-debugging, regression-testing.

**План миграции:** исследовать реальные алгоритмы и логи, извлечь проверенные шаблоны с обезличенными примерами; не переносить секреты/токены и не записывать исторические PASS без проверки.

**Статус:** проект зарегистрирован; конкретные алгоритмы и знания ещё не импортированы.
