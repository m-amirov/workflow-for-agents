# Другие агенты и локальные модели

Целевые направления: Gemini CLI, локальные кодовые модели, агентные фреймворки и будущие клиенты.

Для каждого адаптера нужно определить:
- поддерживает ли клиент Agent Skills нативно;
- где располагаются инструкции, как происходит discovery;
- какие инструменты и разрешения доступны;
- каким образом включаются/обновляются избранные Skills;
- как воспроизвести positive/negative trigger tests;
- как управлять конфликтом глобальных и проектных правил.

Нельзя обещать автоматическую совместимость простым копированием файлов. При отсутствии нативной поддержки Skill нужен безопасный адаптер, который передаст только нужные инструкции и корректно вызовет доступные инструменты.

**Статус:** исследование и реализация запланированы, интеграционных тестов пока нет.
