# Claude Code (планируемый адаптер)

Цель: использовать тот же источник Skills, переводя лишь необходимые соглашения об инструкциях и расположении каталогов.

Обычно для project-local skills используется `.claude/skills/`, для user-local — `~/.claude/skills/`; проектные инструкции Claude Code следует вести в поддерживаемом им формате и сверять с актуальной документацией.

Не добавлять отдельную расходящуюся копию Skill. Адаптер должен:
- определять совместимость;
- копировать/синхронизировать выбранные навыки;
- не перезаписывать локальные изменения без предупреждения;
- проверять обнаружение навыка реальным клиентом.

**Статус:** план; интеграционные проверки ещё не проводились.
