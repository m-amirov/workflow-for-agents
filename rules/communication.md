# Отчёт агента

Обязательный итог для технических задач:

- **Сделано:** конкретные изменения и их расположение.
- **Проверено:** реально выполненные команды, результат и объём проверки.
- **Не проверено:** отсутствующие проверки с причиной.
- **Риски:** ограничения, регрессии и открытые вопросы.
- **Дальше:** один конкретный следующий шаг, если работа не завершена.

Для изменений кода/конфигурации кратко фиксировать `DOCS_IMPACT` (NONE/LOCAL/SIGNIFICANT/UNKNOWN), `USER_ACTION_REQUIRED` (YES/NO) и конкретные `USER_ACTIONS` только при их наличии. `UNKNOWN` не означает, что документация уже актуальна.

Не называть релиз успешным по предварительным признакам. Не выдавать план за реализацию. Избегать избыточных сообщений и необоснованных обещаний.
